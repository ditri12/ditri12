# ניהול צי רכב - תוכנה שולחנית

תוכנת Windows (פועלת גם ב-Linux/macOS) לניהול צי רכב במקום העבודה: טסט, ביטוח, טיפולים, תיקונים, קילומטראז׳, ותחזיות אוטומטיות.

## מה התוכנה עושה

| יכולת | פירוט |
|---|---|
| הקמת רכב | מספר רישוי, יצרן/דגם/שנה, נהג, תוקף טסט, תוקף ביטוח, הערות |
| טיפול אחרון | תאריך, קילומטראז׳, מוסך, מה נעשה, עלות - וגם היסטוריית טיפולים מלאה |
| תיקונים | תיאור התיקון, באיזה מוסך בוצע, תאריך, קילומטראז׳, עלות |
| קילומטראז׳ | הזנת קריאות מתי שרוצים; קריאות מטיפולים ותיקונים נספרות אוטומטית |
| ממוצע נסועה | ק״מ ליום / לחודש לפי הקריאות של השנה האחרונה |
| **טיפול הבא** | כל 15,000 ק״מ **או** שנה מהטיפול האחרון - המוקדם מביניהם. המערכת מחשבת לפי הממוצע באיזה תאריך משוער יגיע הרכב ל-15,000 ק״מ ומשווה לתאריך השנתי |
| **צפי נסועה שנתית** | לפי הקילומטראז׳ המדווח והממוצע: כמה ק״מ הרכב צפוי לצבור עד סוף השנה. התראה אם הצפי עובר 35,000 ק״מ |
| התראות | טסט/ביטוח שפגו או עומדים לפוג (ברירת מחדל 30 יום), טיפול באיחור/קרוב, חריגה ממכסת הנסועה |
| ייצוא | ייצוא טבלת הצי ל-CSV (נפתח באקסל) |

הערכים 15,000 ק״מ / 12 חודשים / 35,000 ק״מ / 30 יום ניתנים לשינוי בחלון **הגדרות**.

## התקנה והפעלה

### אפשרות 1 - קובץ התקנה (מומלץ)

1. בדף **Releases** של המאגר (https://github.com/ditri12/ditri12/releases) הורידו את `FleetManager-Setup-x.y.z.exe`.
2. הפעילו את ההתקנה. היא מתקינה למשתמש הנוכחי (ללא הרשאות מנהל), יוצרת קיצור דרך בתפריט התחל ובשולחן העבודה, ומוסיפה הסרה דרך "הוספה והסרה של תוכניות".
3. בהפעלה הראשונה Windows עשוי להציג אזהרת SmartScreen (קובץ לא חתום) - לחצו "מידע נוסף" ואז "הפעל בכל זאת".

קיימת גם גרסה ניידת `FleetManager.exe` (קובץ יחיד, ללא התקנה) באותו דף.

כל דחיפה לקוד בונה את שני הקבצים גם ב-**Actions** (הורדה דרך Artifacts); הגרסה העדכנית מתפרסמת אוטומטית בדף Releases תחת `fleet-v<גרסה>` (הגרסה נקבעת ב-`fleet_app/__init__.py`).

### אפשרות 2 - הרצה מקוד המקור

דרוש Python 3.10 ומעלה.

```bat
run.bat
```

הסקריפט מתקין את הספרייה הנדרשת (PySide6) בפעם הראשונה ומפעיל את התוכנה. ב-Linux/macOS: `./run.sh`.

### בניית קובץ ההפעלה בעצמכם

על מחשב Windows עם Python:

```bat
build\build_exe.bat
```

הקובץ נוצר ב-`dist\FleetManager.exe`. ליצירת קובץ התקנה מלא יש להתקין [Inno Setup 6](https://jrsoftware.org/isinfo.php) ולהריץ:

```bat
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" /DAppVersion=1.0.0 /DSourceDir=..\dist build\installer.iss
```

התוצאה: `dist\FleetManager-Setup-1.0.0.exe`.

## איפה נשמרים הנתונים

כל הרישום נשמר בקובץ אחד, `fleet.db`, בתוך תיקייה שאתם בוחרים. בהפעלה הראשונה התוכנה שואלת היכן לשמור:

- **במחשב זה** - `%APPDATA%\FleetManager\fleet.db` (ב-Linux: `~/.local/share/FleetManager/`).
- **תיקייה לבחירתכם, כולל תיקיית רשת** - למשל `\\server\share\FleetData` או כונן רשת ממופה (`Z:\FleetData`). כך כל העובדים עובדים על אותו רישום: מתקינים את התוכנה בכל מחשב ובוחרים בכולם את אותה תיקייה.

אפשר לשנות את התיקייה בכל עת דרך **הגדרות ← תיקיית שמירת הנתונים**. כשעוברים לתיקייה חדשה התוכנה מציעה להעתיק אליה את הרישום הקיים, ואם בתיקייה כבר יש קובץ `fleet.db` היא פשוט עוברת לעבוד עליו. השינוי חל מיד, ללא הפעלה מחדש.

גיבוי = העתקה של הקובץ `fleet.db`. ניתן גם לכפות נתיב דרך משתנה סביבה `FLEET_DB`.

## נתוני דוגמה

```bash
python seed_demo.py demo.db
FLEET_DB=demo.db python fleet_manager.py      # ב-Windows: set FLEET_DB=demo.db && python fleet_manager.py
```

## איך החישובים עובדים

- **ציר הקילומטראז׳** של כל רכב נבנה מכל הקריאות, הטיפולים והתיקונים שהוזן בהם קילומטראז׳.
- **ממוצע יומי** = (קריאה אחרונה − קריאה מוקדמת ביותר בשנה האחרונה) ÷ מספר הימים ביניהן.
- **ק״מ נוכחי (משוער)** = הקריאה האחרונה + ממוצע יומי × ימים שעברו מאז.
- **טיפול הבא**: יעד ק״מ = ק״מ בטיפול האחרון + 15,000; תאריך יעד = תאריך הטיפול האחרון + 12 חודשים. התאריך המשוער להגעה ליעד הק״מ מחושב לפי הממוצע, והמוקדם מבין השניים מוצג. סטטוס "בקרוב" כשנותרו עד 30 יום או עד 1,000 ק״מ.
- **צפי נסועה שנתית** = מה שנסע מתחילת השנה (אינטרפולציה בין קריאות) + ממוצע יומי × הימים שנותרו עד סוף השנה. אם לרכב הוגדר "תחילת שנת נסועה" (למשל תאריך תחילת ליסינג), השנה נספרת מתאריך זה במקום משנה קלנדרית. כשהמעקב התחיל באמצע השנה מוצג גם "קצב שנתי" (ממוצע יומי × 365) ומתקבלת אזהרה אם הוא מעל המכסה.

```
fleet_app/config.py     מיקום קובץ הנתונים
fleet_app/ui_main.py    החלון הראשי (התראות + טבלת הצי)
fleet_app/ui_vehicle.py חלון רכב (כרטיסי מצב, קילומטראז׳, טיפולים, תיקונים)
fleet_app/ui_dialogs.py טפסי הזנה והגדרות
tests/                  בדיקות יחידה: python -m unittest discover -s tests
```
